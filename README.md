
===================================================
               MAZZ LOADER - README (EN)
===================================================

Welcome to MAZZ LOADER. 
This software is an external tool designed to automate the launch of Roblox, 
the injection of Xeno, and the execution of your custom menu.

Follow these steps carefully to avoid any crashes or errors.

---------------------------------------------------
1. REQUIREMENTS (What you need)
---------------------------------------------------
- Windows 10 or 11 (64-bit).
- The Roblox Player application installed.
- The Xeno executor (version 1.3.65 or higher).
- Your antivirus (Windows Defender or other) might block the .exe. 
  If the software does not open, allow it in your antivirus settings.

---------------------------------------------------
2. INSTALLATION (Where to place the files?)
---------------------------------------------------
For the loader to work, you MUST follow the exact folder structure.
The loader's code looks for Xeno in a specific location.

1. Create a folder named "Mazz" on your Desktop (C:\Users\YOUR_NAME\Desktop\Mazz).
2. Place the "MAZZ_Loader.exe" file inside this folder.
3. Inside this same folder, create a subfolder named "dist".
4. Place your unzipped Xeno folder inside this "dist" subfolder.

The final structure should look like this:
C:\Users\YOUR_NAME\Desktop\Mazz\MAZZ_Loader.exe
C:\Users\YOUR_NAME\Desktop\Mazz\dist\Xeno-v1.3.65\Xeno.exe

---------------------------------------------------
3. USAGE (How to launch the cheat)
---------------------------------------------------
1) Double-click on "MAZZ_Loader.exe".
2) The text "! Bagdad" will appear in the center of the screen for 3.5 seconds.
3) Then, the loader interface will appear.
4) Click on the "LANCER LE CHEAT" button.
5) The software will do everything automatically:
   - It opens Roblox.
   - It waits 15 seconds (for the game to load).
   - It opens Xeno.
   - It waits 8 seconds.
   - It pastes your script (the loadstring) into Xeno.
6) The software will display "TERMINÉ" (Finished).
7) In Xeno, click on "Attach" (or Attach to Roblox) and then "Execute".

---------------------------------------------------
4. IN-GAME KEYBINDS (For the MAZZ menu)
---------------------------------------------------
Once the script is executed, press these keys in Roblox:

- [F2] : Show / Hide the MAZZ menu.
- [Z]  : Enable / Disable Aimbot.
- [X]  : Enable / Disable ESP (Box).
- [C]  : Enable / Disable ESP (Health).
- [V]  : Enable / Disable ESP (Name).
- [1]  : Decrease Aimbot speed.
- [2]  : Increase Aimbot speed.

---------------------------------------------------
5. TROUBLESHOOTING (If it doesn't work)
---------------------------------------------------
> "Xeno.exe introuvable" (Xeno.exe not found): 
  Check that Xeno is in the "dist" folder as shown in step 2.

> The button stays stuck on "LANCEMENT EN COURS..." (Launching...):
  The software clicked the button, but the Xeno window took too long to open. 
  Wait a bit, and if nothing happens after a minute, restart the application.

> Nothing happens after pasting:
  Manually go to the Xeno window, press Ctrl + V, and click Execute.
